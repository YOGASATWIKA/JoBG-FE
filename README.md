# JoBG-FE

Frontend **JoBG**: portal lowongan kerja & magang untuk pencari kerja pemula.

Repository ini akan berisi:
- **Portal Kandidat**: daftar, profil dari CV, bukti, lowongan, melamar, tes, status
- **Dashboard HR**: lowongan & kriteria, alur rekrutmen, tes, penilaian, keputusan

> **Status: fase perencanaan.** Belum ada kode. Pilihan teknologi belum ditentukan.

Dokumen perencanaan (PRD, desain, keputusan) disimpan terpisah di folder `docs/` proyek JoBG.

⚠️ Repository ini berpotensi publik: **jangan** commit data pribadi asli atau rahasia (password, API key).
